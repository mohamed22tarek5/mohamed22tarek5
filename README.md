## 🚀 Featured Engineering Projects

### 1. 60 W Photovoltaic Renewable Energy System with IoT Monitoring
**Graduation Project | Grade: Excellent**

Designed, modeled, implemented, and monitored a 60 W photovoltaic energy system.

- Designed and simulated the PV system using **MATLAB/Simulink**.
- Implemented a **TL494-based buck converter** for battery-charging regulation.
- Developed a conventional inverter using a **555 timer IC** for basic AC power conversion.
- Implemented an **EGS002-based SPWM inverter**.
- Evaluated output voltage waveform, frequency stability, and conversion performance under different load conditions.
- Built an IoT monitoring board for real-time data collection and analysis using **Firebase**.
- Developed a Firebase-connected web dashboard to display system measurements.

**Technologies:** MATLAB/Simulink, TL494, 555 Timer, EGS002, SPWM, Power Electronics, Firebase, IoT.

### 2. PLC Programming Projects — Siemens TIA Portal

Developed and tested PLC Ladder Logic programs for industrial automation scenarios.

Examples include:
- Color Detection
- Pick-and-Place
- Elevator Control
- Automatic Filling Tank
- Traffic Light Control
- Cyclic Motor Operation
- Temperature Monitoring

Applied PLC instructions and programming concepts including **timers, counters, comparators, and arithmetic operations** to implement automated sequences.

**Technologies:** Siemens TIA Portal, PLC, Ladder Logic, Factory I/O.

### 3. Classic Control Projects

Designed and implemented control circuits for motor and sequential-control applications.

- Sequential Motor Control.
- Star-Delta Starter with Forward/Reverse operation.
- Automatic Washing Machine Controller.
- Timed Motor Operations.
- Prepared wiring diagrams and tested circuit functionality under different load conditions.

**Technologies:** Classic Control, Contactors, Timers, Motor Control, Electrical Wiring Diagrams.

### 4. Smart Blind Glasses

Developed a wearable assistive prototype to support obstacle detection and navigation.

- Used ultrasonic sensors to detect nearby obstacles.
- Implemented vibration-motor and buzzer feedback to communicate detection alerts.
- Focused on portable design and low-power operation.
- Refined the prototype through user testing.

**Technologies:** Arduino, Ultrasonic Sensors, Vibration Motor, Buzzer, Embedded Systems.

### 5. RFID-Based Attendance & Person Counter

Designed an RFID-based system for attendance tracking and room-occupancy counting.

- Implemented RFID-based identification and attendance logging.
- Added occupancy counting to estimate the number of people in a room.
- Implemented occupancy-based automatic lighting control.
- Built an administrator interface for data visualization and system access.

**Technologies:** RFID, Microcontrollers, Embedded Systems, Automation, Data Visualization.

### 6. Smart Home System

Full home automation with mobile app control.

**Technologies:** ESP32, IoT, Mobile App.

### 7. Health Monitoring IoT System

Remote patient monitoring with real-time cloud analytics.

**Technologies:** IoT, Cloud Dashboards.

### 8. PCB Design Practice

Practiced the main stages of PCB development using Altium Designer.

- Schematic capture and component selection.
- Footprint assignment.
- Component placement and PCB routing.
- Design Rule Checking (DRC).

**Technologies:** Altium Designer, KiCad, EAGLE, Schematic Design, PCB Layout, DRC.
